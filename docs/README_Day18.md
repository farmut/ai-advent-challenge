# Day 18: HTTP+SSE-транспорт и фоновый сборщик отчётов

Petstore MCP-сервер получает постоянный режим и фоновую горутину.

## Что нового
- **HTTP+SSE-транспорт** сервера (persistent-service режим через `-addr`).
- **Фоновый сборщик отчётов**: горутина периодически снимает снапшоты проданных питомцев независимо от вызовов агента — инструменты `report_start_collection` / `report_stop_collection` / `report_collection_status` / `report_show_sold`.
- Число инструментов выросло до **22**.
- Makefile-цель `run-agent` авто-стартует MCP-сервер в SSE-режиме и пишет конфиг агента.
