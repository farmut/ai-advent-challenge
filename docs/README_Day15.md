# Day 15: review-промпты, PendingPlan и CoT-compliance

Улучшение согласования планов и проверки соответствия.

## Что нового
- Согласования `y`/`yes` заменены на `/yes`-only review-промпты (`reviewPrompt()`) на всех gate FSM (Planning, Execution continue, Validation, resume при старте).
- Поле `PendingPlan`: план сохраняется до показа пользователю — resume после паузы восстанавливает тот же план без повторного LLM-вызова.
- Compliance-проверка стала **chain-of-thought**: чекер-LLM анализирует каждый инвариант по отдельности, затем пишет вердикт `COMPLIANT` / `VIOLATION:` на последней строке; парсер читает только эту строку — промежуточный текст не маскирует нарушение.
