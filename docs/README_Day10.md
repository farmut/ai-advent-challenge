# Day 10: стратегии управления контекстом

Три стратегии работы с контекстом диалога (`--strategy`).

## Что нового
- `sliding-window` — держать последние N сообщений.
- `sticky-facts` — KV-хранилище фактов, переживающее ротацию окна.
- `branching` — независимые ветки диалога с именованными чекпоинтами.
- Управление ветками: `--checkpoint`, `--branch-new`, `--from-checkpoint`, `--branch-switch`, `--branch-list`.
- `--window-size` — размер окна.
- `system_critic.txt` — промпт AI-критика для сравнения стратегий/качества.
