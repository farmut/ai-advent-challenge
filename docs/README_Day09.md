# Day 9: лимит истории и авто-суммаризация

История не растёт бесконечно — старое сжимается.

## Что нового
- Флаг `--history-limit` — максимум сообщений.
- Авто-суммаризация: при превышении лимита старые сообщения суммируются LLM и хранятся в `<history>.summary.txt`, который инжектится обратно как префикс системного сообщения.
