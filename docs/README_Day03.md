# Day 3: системная роль

Добавлено системное сообщение — управление поведением модели через role=system.

## Что нового
- Флаг `--system` — задаёт системное сообщение (персона / инструкции).
- Makefile содержит 6-шаговый пайплайн: 4 параллельных варианта решения → объединённый вход → финальный вызов LLM-ревьюера. Результаты — в `report_*.txt` / `final_report.txt`.

## Prompt-файлы
- `query.txt` — запрос; `system.txt` / `system_*.txt` — системные сообщения разных персон; `query_by_steps.txt` — пошаговый вариант. Читаются Makefile-целями в рантайме.
