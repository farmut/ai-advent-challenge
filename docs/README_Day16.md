# Day 16: MCP-клиент (Model Context Protocol)

Агент учится подключаться к внешним MCP-серверам инструментов.

## Что нового
- Поддержка двух транспортов MCP:
  - **stdio** — сервер как дочерний процесс, JSON-RPC 2.0 через stdin/stdout.
  - **sse** — HTTP + Server-Sent Events.
- Серверы объявляются в YAML-конфиге.
- Новые slash-команды `/mcp-*` (список серверов, список инструментов и пр.) внутри интерактивной сессии.

Day17 добавляет собственный Petstore MCP-сервер — начинается двухкомпонентный workspace (`agent/` + `mcp-server/`).
