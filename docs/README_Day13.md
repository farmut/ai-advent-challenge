# Day 13: интерактивный режим и FSM задачи

Интерактивный агент с машиной состояний и pause/resume.

## Что нового
- Флаг `--interactive` — 4-фазная FSM задачи: **Planning → Execution → Validation → Done**.
- Полная поддержка pause/resume: состояние сохраняется в `<history>.task.json`; задачу можно возобновить после перезапуска.
