# Day 14: инварианты (жёсткие ограничения)

Абсолютные ограничения, проверяемые на каждой фазе FSM.

## Что нового
- Флаг `--invariants` — инварианты из Markdown-файла, инжектятся в каждый системный промпт Planning и Execution.
- Три автоматических compliance-gate:
  - **Task Gate** — проверка описания задачи на итерации 1.
  - **Plan Gate** — до 3 «тихих» ретраев перед показом предупреждения.
  - **Validation Gate** — авто-возврат в Planning при нарушении.
- Slash-команды `/exit`, `/restart`, `/pause` работают на любом промпте FSM.
