# Day 4: температура генерации

Добавлен контроль случайности ответа.

## Что нового
- Флаг `--temperature` (0.0–2.0).
- Makefile-цель `run-temperature` генерирует 3 ответа при temp 0 / 0.7 / 1.2 в `temperature_result.txt`, затем вызывает LLM-ревизора для сравнительной оценки.
- `system_revisor.txt` — системный промпт ревьюера для сравнения температур.
