# Project Invariants

These are absolute constraints the agent must never violate.
Edit this file freely — it is plain Markdown.

## Architecture
- Для разработки используем только Clean Architecture

## Technology Stack
- Используем Golang версию 1.25+ 
- Разрешено использованием стандартной библиотеку Golang
- Приложения создается для работы с чатами Matermost и Telegram, разрешено использование только официальные библиотеки от создателей этих чатов. 
- Возможно расширение фунциональности официальных библиотек за счет самостоятельной реализации недостающего функционала, внутри кода приложения
- Для реализации логирования используем только log/slog библиотеку. Вывод должен быть только в stdout. 
- Хранить данные можем либо в JSON файлах либо в PostgreSQL

## Business Rules
- Каждая функция должна прокоментирована кратким описанием  что она делает
- Для каждой фунции должен быть unit-тест.
